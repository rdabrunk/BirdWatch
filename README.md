# BirdWatch

A watchOS app for logging bird sightings in the field. Add species by 4-letter alpha code or common name, tap to increment counts, and swipe to adjust or remove.

## Features

- **Active checklist** — tap any species row to add a count, swipe left for −1, swipe right to delete
- **Smart search** — alpha-code prefix matches float to the top, followed by common name matches
- **~2,176 ABA species** — bundled taxonomy loaded into SwiftData on first launch, no network required

## Requirements

- Xcode 16+
- watchOS 11.5+

## Getting Started

Open `BirdWatch.xcodeproj` in Xcode, select a watchOS simulator or paired device, and run the **BirdWatch Watch App** scheme.

## Taxonomy Data

The bundled `BirdWatch Watch App/aba_birds.csv` is generated by the `BirdData/` pipeline in the parent directory:

```bash
cd ../BirdData
python3 bird_data.py   # requires pandas
```

This merges the [eBird taxonomy](https://www.birds.cornell.edu/home/ebird-taxonomy/) with [IBP alpha codes](https://www.birdpop.org/pages/birdSpeciesCodes.php) and outputs a four-column CSV (`alphaCode`, `commonName`, `scientificName`, `ebirdCode`). After regenerating, copy the result into `BirdWatch Watch App/aba_birds.csv`.
